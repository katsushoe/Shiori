# Shiori v1.1.3

Shiori v1.1.3 adds the standard MCP version tool and completes package and
security documentation.

## Changes

- Adds a `get_version` MCP tool that returns the running Shiori server name
  and version, matching the shared MCP server tooling standard.
- Adds `PACKAGES.md` and `SECURITY.md` as the package inventory and security
  reference documents.
- Reworks MCP client setup guidance around explicit values, scope,
  alternatives, and staged verification.
- Standardizes README sections, command labels, and specification heading
  hierarchy.
